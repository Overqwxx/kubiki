# ТЕХНИЧЕСКОЕ ЗАДАНИЕ
на разработку консольного приложения «Решение квадратных уравнений» (Kubiki)

ЧАСТЬ 1. ТРЕБОВАНИЯ ЗАКАЗЧИКА

1. Цель
Создать простую и надежную программу, которая поможет студентам и школьникам быстро и без ошибок решать квадратные уравнения любой сложности.

2. Область применения
Программа предназначена для использования в учебном процессе (уроки математики, информатики, выполнение домашних заданий), а также для личного использования.

3. Определения, термины, сокращения
  ПО – Программное обеспечение.
  ТЗ – Техническое задание.
  Квадратное уравнение – уравнение вида Ax^2 + Bx + C = 0, где A не равно 0.
  Дискриминант – величина, помогающая найти корни уравнения.
  Комплексные числа – числа, которые получаются, если извлечь корень из отрицательного числа (содержат букву i или j).

4. Краткое описание
Программа должна спрашивать у пользователя три числа (A, B, C) или брать их из файла, а затем выдавать ответ: какие корни у этого уравнения. Если корней нет (они получаются комплексными), программа должна так и написать. Также программа должна уметь делать «бэкап» (сохранять копию введенных данных).



ЧАСТЬ 2. ТРЕБОВАНИЯ РАЗРАБОТЧИКА

1. Обзор ПС (Программной системы)
  Пользовательский интерфейс: Консольный (текстовый) интерфейс. Меню с выбором действий (1, 2, 3, 4).
  Аппаратный интерфейс: Стандартные устройства ввода-вывода (клавиатура, монитор). Ограничений по памяти нет, требуется любой ПК с установленным Python.
  Программный интерфейс: Взаимодействие с файловой системой (чтение и запись файлов .txt).

2. Функциональное описание
  Функция 1: Ввод коэффициентов A, B, C вручную через консоль.
  Функция 2: Чтение коэффициентов из текстового файла (data/input.txt).
  Функция 3: Вычисление дискриминанта и корней уравнения (включая обработку ветки с комплексными корнями).
  Функция 4: Вывод результата на экран и сохранение в файл (data/output.txt).
  Функция 5: Создание резервной копии файла коэффициентов (data/backup_input.txt).
  Функция 6: Восстановление файла из резервной копии.
  Функция 7: Обработка исключительных ситуаций (ввод букв вместо цифр, деление на ноль при A=0).

3. Характеристики пользователя
Пользователь должен обладать базовыми навыками работы с компьютером (уметь открыть программу и вводить числа с клавиатуры). Знание языков программирования не требуется.

4. Ограничения
  Программа работает только в операционных системах семейства Windows/Linux/MacOS.
  Для работы необходим установленный интерпретатор Python версии 3.6 или выше.
  Программа не имеет графического интерфейса (только текст в консоли).

5. Допущения и зависимости
  Предполагается, что пользователь корректно вводит числа с клавиатуры.
 Файлы с данными (input.txt) должны находиться в папке data в корне проекта.
