# Техническое задание на разработку консольного приложения «Решение квадратных уравнений»

## 1. Общие сведения
Название проекта: Kubiki (Quadratic Solver).
Язык программирования: Python 3.
Назначение: Программа для нахождения корней квадратного уравнения \(Ax^2 + Bx + C = 0\).

## 2. Функциональные требования
Программа должна выполнять следующие действия:
1. Считывать коэффициенты \(A, B, C\) двумя способами (по выбору пользователя):
   - Ввод с клавиатуры (через консоль).
   - Чтение из текстового файла `input.txt`.
2. Вычислять корни квадратного уравнения.
3. Обрабатывать **комплексные корни** (когда дискриминант \(D < 0\)).
4. Выводить результат двумя способами:
   - В консоль.
   - В текстовый файл `output.txt`.
5. Обрабатывать ошибки:
   - Если \(A = 0\) (уравнение не является квадратным).
   - Если введены буквы или символы вместо чисел.
6. Выполнять резервное копирование таблицы введенных коэффициентов в отдельный файл.

## 3. Требования к документации
- Наличие файла `README.md` на русском и английском языках с инструкцией по запуску.
- Наличие регламента технического обслуживания (описание процедуры бэкапа).
- Наличие набора тест-кейсов в папке `tests/`.
