# РЕГЛАМЕНТ ТЕХНИЧЕСКОГО ОБСЛУЖИВАНИЯ (ТО) ПО «Kubiki»

## 1. Паспортная часть и общие положения

1.1. Назначение документа
Настоящий регламент определяет порядок, периодичность и содержание работ по техническому обслуживанию консольного приложения «Kubiki» 
(Калькулятор квадратных уравнений). Целью внедрения регламента является минимизация простоев, предотвращение потери пользовательских данных 
(коэффициентов) и обеспечение стабильной работы программного обеспечения.

1.2. Область применения
Правила распространяются на:
*   Программное обеспечение: консольное приложение на языке Python (файл src/main.py).
*   Файловую систему: папку data (файлы входных данных input.txt, результатов output.txt и резервных копий backup_input.txt).
*   Аппаратное обеспечение: персональный компьютер пользователя (или сервер), на котором запускается интерпретатор Python.

1.3. Роли участников
*   Пользователь: вводит данные, запускает программу, выполняет базовые операции по резервному копированию (через меню программы).
*   Администратор / Разработчик: отвечает за установку обновлений (через Git), проверку целостности файлов программы и восстановление 
данных в случае критических сбоев.

## 3. Контроль качества и отчетность

3.1. Параметры контроля
Оценка качества работы системы и проведения ТО осуществляется по следующим метрикам:
*   Стабильность: Отсутствие ошибок (красных сообщений) при вводе корректных данных.
*   Сохранность данных: Наличие файлов input.txt, output.txt и backup_input.txt в папке data после каждого цикла работы.
*   Корректность вычислений: Совпадение результатов программы с результатами ручного счета или онлайн-калькуляторов (включая проверку комплексных корней).

3.2. Формы документов
Фиксация выполнения регламента ведется в электронном виде:
*   Журнал учета: История коммитов в Git (команда git log), где фиксируются все изменения и обновления кода.
*   Отчет о сбоях: Описание проблемы в разделе Issues на платформе GitHub (если приложение используется командой разработчиков).
